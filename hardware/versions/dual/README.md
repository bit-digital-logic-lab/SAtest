# E2：每PE两个独立三级乘法器

> 存储边界更新：本页是既有触发器实现的测量快照。后续使用16bit同步SRAM宏须遵守[真实SRAM约束与驻留数据流](../../SRAM约束与驻留数据流.md)，不能将本页周期/面积当成已接宏结果。


每拍同时接收 `a0,b0,a1,b1`：它们是同一输出的相邻 `K=2i,2i+1`，不是两个输出，也不复用乘法器。每PE两个独立 `kwt_mul` 实例，各自三级；乘积与旧和经组合3:2后，由单拍28位CPA写回唯一驻留和。

源码顺序：`kwt_csa28`/`kwt_acc28` → `kwt_pe_dual` → `kwt_dual4x4` → `kwt_array_dual` → 共用 `kwt_block32(K_LANES=2,TAIL_CYCLES=0)`。四个4×4，A/B分别广播；原部分和按行上传/下载，各8拍，不加反压或影子页。8×8核心输入带宽为每拍16个A12＋16个W10，共352bit；32×32块存储在每拍提供两个相邻K的读数据。

## 本版的优势与代价

- **优势**：两个独立三级乘法器同时服务一个输出，共享一份28位累计状态；每拍归约两个相邻K，峰值38.4GOPS@150MHz。完整32×32任务608拍，比普通版少29.63%，三个完整模块中计算时间最短；现有冻结24例仍满足0.3%误差要求。
- **代价**：A/B广播带宽由176增至352bit/拍，乘法器128个；核心面积相对普通版增加约81%，完整模块增加约20.78%。单拍反馈包含3:2和CPA，时序提升需另测；ACC28与原INT32不是同一溢出协议。
- **适用**：能提供双K带宽，希望在保留8×8及现有行移位协议的前提下缩短计算时间。固定上传/下载和等待未减半，所以整任务并不会随峰值吞吐一起翻倍。


## 实测周期与数值

- 单PE512对输入、520次逐拍检查通过，独立核对两个乘法器的三级延迟、空拍、零通道、补码端点和回绕。
- 28例、612,728个矩阵输出逐点通过，含奇数K/尾块、全零、稀疏、边界、12层各2个真实样本及末块再次驻留累加。
- 每个8×8/K32：上传8＋发射16＋末向量等待5＋flush1＋下载8＝38拍；完整32×32任务608拍。
- 99×64×256需64个32×32任务，共38912拍；150MHz下259.413µs，有效吞吐12.5053GOPS。这里不含主机标量装载/读回、外部DMA/CPU，尚未接入完整SoC。
- 峰值128MAC/拍、38.4GOPS（一次乘与一次加计2OP）。综合结构中有128组12×6和128组12×5部分积，共256个`$mul`，分别组成128个完整12×10乘法器。

ACC28采用补码模2²⁸回绕，输入旧和取低28位，输出符号扩展到32位；不同于旧版本的INT32回绕，也不是38位饱和。冻结24例真实参数无溢出，归约配对边界最大绝对值4,593,325，最大NRMSE=0.14338871%（<0.3%）。人为大bias/极端用例按独立28位参考比较，不宣称其与INT32结果相等。
