# CSA共享行加法器：周期与面积实测

旧版为每PE反馈CSA＋独立CPA；新版为每PE驻留sum/carry＋每4×4共享四路两拍CPA。两版均为64个A12W10乘法器、INT32回绕、三拍乘法、K向量II=1。

旧版代码取本地`fcba1c7`（RTL对应`fb7b3be`）；SAtest中的旧版快照提交为`9e94392`。新版代码和本报告同次发布；两版文件SHA256见各自source_manifest.json。旧版由独立快照重新仿真、重新映射，未直接复用上轮面积。

## 仿真周期

| 指标 | 旧版逐PE加法 | 新版共享行加法 |
| --- | ---: | ---: |
| 每8×8、K32 | 171 | 176 |
| 32×32×32任务 | 2736 | 2816 |
| 99×64×256层，64个任务 | 175104 | 180224 |
| 150MHz折算层延迟 | 1.16736 ms | 1.201493 ms |
| 有效吞吐，MAC计2次操作 | 2.778947 GOPS | 2.700000 GOPS |

周期不包含外部A/B/C装载、CPU读回或DMA总线等待。两版都实际跑过28例、612728个输出逐点比对；包含随机尾块、零/稀疏/补码极值、12层各2个真实样本、保留B/C重复累计。当前其他两架构也各28例通过，共84例。每个32块的周期与512次发射均由测试台断言。

32×32阶段分解：LOAD 1024、RUN 512、WAIT 80、FLUSH 16、STORE 1024拍，两版一致；TAIL从80拍变160拍。因此总周期增加80拍（2.924%），有效吞吐下降2.841%。

## 同库综合与时序

ICsprout55 H7CL，SS/1.08V/125°C；Yosys＋Slang＋ABC映射，ABC目标6666.667ps，OpenSTA周期6.666667ns。输入/输出延时0.5ns、输入转换0.1ns、时钟转换与不确定性各0.1ns、输出负载0.01pF。库SHA256见result.json，两版本须相同。

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 8×8计算核 | 0.31236268 | 0.23360064 | 25.21% | 125102 / 101837 | 16461 / 10084 | 3.510933 / 2.287006 |

两版四个映射目标均通过Yosys check及150MHz setup检查，TNS为0。面积是映射标准单元面积之和，不是布线后芯片面积；未含时钟树、寄生和SRAM宏。32×32模块把55296位A/B/C存储映射为触发器与选择器，因此共同存储成本会稀释核心面积降幅。

## 数据流变化

PE不再收集成对乘积或把sum逐次送往独立累计器，而是每拍压缩`旧sum＋旧carry＋乘积`，两数之和保持INT32数学等价；零乘积保持两数。oldsum/bias直接装入sum，carry清零。每块四路共享加法器只在计算结束工作，结果写回原sum，carry清零；无影子结果页。

块0/1交替送行：0行/0行、1行/1行、2行/2行、3行/3行；块2/3同时按同样日程执行。每个块仍有自己的四路组，整个8×8合计16路CPA，旧版为64路。每块隔拍送出一行；第一拍锁存低位和与高位操作数，第二拍写回PE。随后原64拍链逐项排出。

核心触发器由16461降为10084，减少6377个；删除逐PE首项缓存、前送sum缓存、独立CPA中间状态与收尾状态机，增加块级四路加法和行选择。主要取舍是增加行选择、改变压缩反馈路径；新版setup余量下降但仍满足150MHz。

## 原始报告与复现

`previous/`、`shared/`各含core/block的stat.json、完整synth.log、SDC、关键路径、slack/TNS、OpenSTA日志和result.json；simulation.json和simulation.log记录逐例实测。power报告仅为统一活动率估计，不能当作真实工作负载功耗。

在对应代码快照运行：

```bash
python3 hardware/run.py --version inside_csa --full --synth
python3 hardware/synth.py --scope all --version inside_csa
```

新版额外支持`--output 结果目录`隔离报告。上面的面积由Yosys JSON单元统计与Liberty面积求和交叉核对。
